# Capture

Accept explicit requests, including tentative ideas; automatically capture clear user-owned commitments during current work without per-item approval.
For evidence passed with `capture: none`, return candidates without task writes; handle explicit user capture requests as separate operations.

1. Establish the outcome and ownership. Quoted promises, hypothetical examples, and team suggestions do not establish ownership; ask if uncertain.
2. Search for the same outcome/source before creation; add evidence to a match, resolve ambiguous matches, and keep distinct obligations separate.
3. Prepare brief content and supported dates using [task content](content.md); preserve meaning and source references.
4. Persist creation in Inbox before [triage](triage.md); do not infer commitment from capturing an idea.
Confirm verified captures with references; batch confirmations at a natural stopping point.
