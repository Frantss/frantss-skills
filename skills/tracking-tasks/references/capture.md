# Capture

Accept explicit requests, including tentative ideas. Automatically capture clear outcomes owned by frantss, pending or already completed, without requiring a prior promise or per-item approval.
Require a specific outcome and completion condition in the title/context. Establish ownership from a clear assignment, accepted follow-up, or performed implementation; participation, ticket creation, PR opening, reviews, and discussions alone establish only activity. Uncertain automatic candidates stay unsaved with a focused question.
For `capture: none`, return candidates without task writes/handoffs; explicit capture requests are separate operations.
Match existing outcome and scope before creation, using source links as supporting identity. Shared Jira/PR links alone never merge distinct subtasks; multiple PRs for one outcome remain links on that task.
Save creation in Inbox before [triage](triage.md), including directly discovered completed outcomes; preserve supported dates, meaning, and links. Capturing a tentative idea never establishes commitment.
Confirm verified captures with references, batching at a natural stopping point.
