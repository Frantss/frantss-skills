# Source workers

Always attempt source-search delegation through available native sub-agents; prefer the smallest, fastest available model with the required tools, aiming below the main model. Use the host's model choices, not hardcoded names; disclose when model selection or a smaller suitable model is unavailable.
Partition independent provider/instance/location searches into bounded workers; parallelize within host capacity and queue overflow. Combine overlapping searches instead of assigning duplicate scans. Only the coordinator dispatches; workers do not recursively delegate or create persistent tasks/threads.
Start workers with fresh/minimal context when supported. Send only relevant project/source IDs, native instance/identity/locations, exact window/timezone, fixed policy/references, remaining budget/cursor, and output requirements. Give explicit read-only source access and `capture: none`; workers neither write records nor capture/triage tasks, and return questions to the coordinator.
The main agent divides the existing 20-call/50-item project/source budget across workers/branches and reserves verification/write calls. Count discovery, retries, fallbacks, and capture handoffs cumulatively; spawning workers never resets limits. Workers stop at their assigned allowance.
Workers return concise findings, native deduplication identities, source links/locators, actors/occurrence dates, task candidates, coverage/gaps/cursors, and actual calls/items used. Keep raw excerpts/conversation history out of the main context unless needed to resolve a specific ambiguity; report actual model/cost only when exposed.
The main agent checks scope/attribution/dates, merges and deduplicates results, resolves uncertainty, and alone hands task changes/reports to their workflows. Use a focused follow-up or more capable worker only when needed within remaining budget. If delegation/tools fail, disclose the reason and perform only missing work directly when permitted/capable; otherwise return partial coverage, without repeating completed scans or widening scope.
