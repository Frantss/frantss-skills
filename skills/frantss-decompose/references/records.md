# Live Markdown document and stable IDs

## Document structure and updates

Use frantss's destination or workspace convention; otherwise choose an unused `<topic>-breakdown.md` path in the workspace.
Organize the document by problem, context, goals, constraints, approaches, breakdown, decisions, deferred notes, and open questions.
Keep the current stage and part visible. Mark parts pending, in discussion, or agreed; future sections remain pending.
Maintain one evolving document. After each substantive exchange, update relevant records and the stage before asking the next round.
Record sources where available. Distinguish reported facts, assumptions, proposals, and agreements; frantss's acceptance determines agreement.
Show focused changes and link the file during the conversation instead of repeating its full contents.

## Record identities

Give every distinct substantive point its own stable ID, including context, goals, constraints, decisions, parts, questions, and other agreements.
Split combined claims into separate records. Keep one authoritative entry per point and cross-reference its ID elsewhere.
IDs use one or two uppercase letters, a hyphen, and three digits, such as `CO-001` or `R-012`.
Allocate increasing numbers independently per prefix within the document. Preserve an existing prefix scheme.

| Default prefix | Record type |
| --- | --- |
| CO | Context fact or assumption |
| CN | Constraint |
| G | Goal or success criterion |
| D | Decision |
| A | Alternative |
| P | Part of the breakdown |
| Q | Question |
| R | Other agreed rule or point |

Status is separate from identity: a proposed decision keeps its ID when accepted or rejected.
Keep IDs when records move, wording is clarified, or status changes. Never renumber records or reuse an assigned ID.
If meaning changes, create a replacement with a new ID; retain the old record as superseded and link both records.
When merging or splitting points, retain superseded records and link them to the new records.
Use point IDs in related records, decision reasons, questionnaire rounds, and conversational answers.
