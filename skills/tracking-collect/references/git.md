# Local Git collection

Use read-only Git commands for configured local sources. Verify the exact author email in `identity` and each canonical checkout root in `scope.repositories`. Paths refer to the machine that holds this configuration; Git sources require no configured `instance`.
Resolve each root's canonical `git rev-parse --git-common-dir` against the checkout directory. Linked worktrees share that repository scope. Deduplicate repositories by common directory; distinct clones remain separate. Paths moved since registration need configuration maintenance.
Enumerate configured repositories' local refs, their HEAD, and linked worktree HEADs from `git worktree list --porcelain`; include detached worktree commits. Record the selected tip hashes for resumable scans. Inspect only commits reachable from those tips; do not fetch, change refs, or scan reflogs.
Read full commit hashes, raw author email, author timestamp, committer metadata, parents, and subject. Match the configured email exactly against the raw author email (`%ae`), without mailmap rewriting or author-name/substring matching. Use author time (`%aI`) for the authored event, converted to the requested local calendar window. Keep committer details as context; a matching committer alone does not establish authorship.
Git's usual `--since`/`--until` filters select by committer time, so they cannot establish completeness for an author-time window. Traverse reachable history within budget and filter author times explicitly. Budget exhaustion or missing objects leave coverage partial; keep traversal position and selected tips in the temporary handoff. Never assume author-time ordering.
Deduplicate matching commits, including merges, by canonical common directory and full hash. Keep raw author email, subject, author time, and hash as temporary context; use a verified hosted commit URL when available, otherwise a repository locator plus full hash. Group related commits into concise outcomes; task links retain only relevant locators.
Return repository scopes, selected tips, traversed/matched counts, traversal cursor, and requested author-time window in the handoff. Coverage is complete only after reachable history is exhausted. Shallow/missing history leaves gaps; commits outside selected tips, uncommitted files, deleted history, hosted events, and other devices are outside coverage. Authorship alone does not establish task completion.
