# Triage

Read the inbox and existing projects. Clarify outcomes and project fit; preserve explicit user categorization.

Assign an existing project automatically when evidence clearly identifies it,
such as a named project or a unique configured source mapping. If several
projects fit, ask a focused question and leave the task in the inbox meanwhile.
If none fits, retain the task in the inbox and explain the gap.

An agent may suggest a new project. Mentioning a new name, approving a task,
or requesting assignment to a missing project is not a creation command.
On explicit creation, resolve name and work/personal classification; preserve supplied source mappings.
